¿Dónde vas a realizar la obra?

Introduce el código postal. Es obligatorio para asociar la calculadora al almacén OBRAMAT correspondiente y preparar referencias y fichas de producto por zona.

El código postal se guarda únicamente en este dispositivo. La asociación automática de catálogo, fichas y códigos se mostrará solo cuando exista una fuente OBRAMAT verificable para el almacén seleccionado.
